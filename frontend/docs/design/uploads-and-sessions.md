# 上传队列、会话目录与状态同步

返回 [Frontend 设计](../DESIGN.md)。

## 逐文件串行队列（`use-file-uploads.ts`）

- 首页选文件时即校验 PDF/DOCX、20 个文件和 32 MiB 上限；首次上传创建会话后，逐个调用 `POST /chat/sessions/{id}/files`，后端返回时即完成解析与索引。
- 首页与详情页共用同一串行队列，避免同会话并发重建索引：等待项显示 `Queued`，处理中右侧旋转图标，成功就绪，失败行保留原因与重试入口，单文件失败不阻塞后续文件。
- 重复选择同名文件不会重复排队，已就绪文件不随提问重传。处理中可编辑问题但暂不发送；存在失败文件时需重试或移除后再提问。

## 删除、补传与自动导航

- 首页删除已处理文件调用后端删除接口，移除排队或失败文件只清本地队列；删除失败保留原文件与提示。
- 详情页补传统一走 Sources 里的 `Add files`（阅读原文时先关阅读器回 Sources，窄屏先切 Documents），聊天输入区不放附件按钮。选文件后立即显示进度并保留历史与草稿；回答进行中、删除或恢复连接期间暂不开放补传，空资料会话允许添加文件。
- 详情补传完成后经 `resume` 刷新会话，删除刚补传的文件会同时清理本地就绪占位；窄屏选文件时自动展开来源面板。
- 首页上传队列全部完成后自动跳转 `/tasks/{session_id}`（不要求先提问），未发问题经同页进程内草稿映射交接、不进 URL；队列未完成时不跳转。复制链接到其他标签页通过 `resume` 读取同一文件与历史。

## 会话目录与空闲轮询

- `workspace-list.tsx` 打开菜单时请求 `GET /chat/sessions` 读取后端最近 100 条会话，聚焦或本页更新时重读并丢弃迟到响应，失败显错不回退本地缓存；不再以 `localStorage` 决定可见性，代理到同一 backend 的不同浏览器共享目录。
- `session-store.ts` 只负责本页列表刷新通知与导航草稿交接；历史、资源和运行态始终来自 `/resume`。
- 空闲详情页每 5 秒及重获焦点时刷新服务端快照以同步其他标签页改动：打开文件选择器期间暂停焦点刷新与轮询，选完或取消后恢复；本页上传、删除、提问或接收回答期间停止空闲轮询。服务端快照确认成功后清理本地占位。
