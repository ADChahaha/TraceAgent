# frontend-copy.test.ts

这组测试固定前端运行时文案语言。用户界面、可访问性标签、错误兜底和页面 metadata 都统一用英文；源码里的中文注释不属于运行时文案，不在这个测试约束内。

## 测试链路

```text
读取 frontend/src 下的 .ts / .tsx 文件
  -> 去掉行注释和块注释
  -> 保留字符串、模板字符串和 JSX 文本
  -> 检查剩余源码是否包含中文字符
  -> 如果包含，报告对应源码文件
```

## 测试函数

- `前端运行时文案统一使用英文`：验证 `src/` 中会进入运行时或可访问性树的文案不再混用中文。
