# task-detail.test.tsx 与 task-detail-files.test.tsx

详情组件使用真实会话 hook 和 SSE 解析器，API 由可控流替代。用例按主题拆分为核心问答与布局测试（`task-detail.test.tsx`）及文件上传与跨标签页同步测试（`task-detail-files.test.tsx`）。

## task-detail.test.tsx

- 恢复历史和实时增量，done 不重复文本，引用高亮整份原文中的段落：覆盖历史、实时内容和整篇文档接口，引用不再替换为孤立片段，并验证关闭回到 Sources 后可再次打开同一引用。
- 追问走 POST 流，输入框节点稳定，取消携带当前轮次：确认三个建议问题按钮均不存在，并覆盖多轮输入、稳定按钮与取消结果。
- 窄窗口点击引用自动显示文档，并能返回聊天：保证窄布局不会把证据藏在不可见分栏。
- 用户取消的历史轮次显示取消状态，不再重复报错：用户主动停止不作为执行故障展示。
- 合并被空消息打断的连续工具调用，以友好英文动作名展示且不暴露原始工具名：验证跨空文本 assistant 工具消息合并为单个 `trace-mini` 折叠入口（步骤总数准确），展开后展示 `Browse files`、`Semantic search`、`Keyword search (unavailable)`、`Read passage`，不出现 `ls`/`grep`/`read`/`search_embedding`/`tool activity`。
- 顶栏加号位于左侧菜单旁，默认 36% 左栏分栏且点击引用与切回列表不重置宽度：确认 `+`（New workspace）与最近会话按钮同处顶栏左侧组、不与右侧主题按钮同组，1440px 视口默认左栏 36%（键盘右移两步得 566px），点击引用与关闭阅读器均保持拖拽后的左栏宽度。

## task-detail-files.test.tsx

- 显示原文件下载，删除与补传刷新资源：验证资源 ID、下载 URL 和文件变更接口。
- 来源列表默认不加载原文，搜索过滤文件且清空后恢复列表：验证来源和阅读互斥、搜索无匹配提示及清除过滤后的文件入口恢复。
- 补传立即逐文件处理，列表显示对应转圈并禁止处理期间提问：确认详情页使用相同处理队列，发送在索引更新期间禁用。
- 删除刚补传成功的文件后不留下本地就绪占位：上传、恢复快照、删除后刷新，来源列表必须同时移除服务端资源和本地上传记录。
- 其他标签页修改文件后，当前空闲工作区重新聚焦与轮询均同步最新快照：验证 focus 与 5 秒定时同步恢复最新快照且不重发提问。
- 另一标签页删除已补传文件后，恢复时不重建本地上传占位：上传被服务端快照确认后，远端删除并恢复，不再显示过期的就绪行。
- 回答后使用原有 Sources 入口补传，保留历史和草稿后继续追问：确认聊天没有额外附件按钮，关闭引用阅读后通过原有入口上传到同一 session，刷新后保留历史和草稿并可继续追问。
- 回答期间禁止补传，空资料会话仍可用原有入口添加文件：原有文件输入在运行时禁用，结束后即使没有文档也能添加文件。
- 原有文件选择器打开时焦点和轮询不禁用补传，取消后恢复同步：模拟打开选择器、窗口重新聚焦和选中/取消文件。
