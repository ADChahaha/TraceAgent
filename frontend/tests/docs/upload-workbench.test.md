# upload-workbench.test.tsx

首页测试模拟会话创建、文件上传和首问 SSE，替代旧 QA task 接口测试。

- 按创建会话、上传、首问快照顺序执行，再跳转：首问接受前不能导航，创建会话即写缓存，打开最近会话抽屉后可访问。
- 上传失败不发首问，重试复用同一会话：避免重复创建空会话。
- 追加去重文件、移除文件，Enter 提交而 Shift Enter 换行：覆盖文件列表和键盘交互。
- 无文件不创建会话，选文件即创建但空问题不发送，保留主题和侧栏缩放：确认文件处理不再要求问题，问答仍校验非空。
- 窄窗口默认收起侧栏，仍可打开最近会话：保证小窗口可用。

- 资料工作台提供来源列表和可编辑的问题建议，不显示参考品牌：检查 Agent Gate 首页概览、文件来源列表；点击建议只填入问题，不调用创建接口。

- 选择多个文件立即逐个处理，各自显示状态，完成前阻止发送且发送不重复上传：用可控 Promise 区分排队、处理中与就绪，验证单文件请求、会话复用及发送互斥。
- 移除已处理文件调用后端删除，失败文件不阻塞其他文件处理：验证逐文件失败隔离、重试入口和成功文件的资源删除。

- 文件完成后通知进入固定工作区地址并保留未发送的问题：上传完成即回传 session ID 和当前草稿，不等待首问、不自动提交问题。
