# session-api.test.ts

在 Node 测试环境模拟 fetch 与真实 ReadableStream，验证浏览器和新 backend 契约。

- 创建会话、上传和删除文件使用独立接口：检查路径编码、multipart files 字段和 DELETE。
- 提问用 POST 流，恢复用 GET，取消包含轮次 ID：检查 JSON 请求体和 AbortSignal。
- 文档与证据路径编码为查询参数，原文件保留下载 URL：覆盖目录、全文、段落和原文件入口。
- 流请求拒绝 HTTP 错误和非 SSE 响应：避免把错误页作为正常流消费。
- 解析跨字节分块的中文、CRLF、多行数据和心跳：逐字节输入以覆盖解码和组帧边界。
- 首帧处理后可释放订阅，不等待整个回答：支持首页确认首问后跳转。
- 无效 JSON 流报错而不是默默丢失状态：让连接层触发恢复。
- 取消订阅立即释放正在等待数据的 reader：避免无新消息时无法关闭流。
