# session-state.test.ts

纯状态合并测试模拟 backend session.event，不依赖 React 或网络。

- 增量按消息 ID 追加，done 完整正文替换，不重复拼接：同时保证不修改输入快照。
- 相同文本的不同用户消息和不同重试均保留：以 ID 而不是正文去重，旧尝试标记失败。
- 工具按调用 ID 更新，取消后忽略迟到事件：取消使未完成消息变为 interrupted。
- 旧轮终态不能清空新轮，新轮开始可追加：保护跨轮运行状态。
- `session.updated` 更新会话标题且不干扰正在进行的活跃轮：验证会话级标题更新事件仅同步 `state.title`，保留当前活跃轮次与消息项。
