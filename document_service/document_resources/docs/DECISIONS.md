# document_resources 关键决策

归属 [文档资源设计](DESIGN.md)，记录会话文档归档、索引与发布模块的长期取舍。

## 1. 增删文件保留未变文档路径、编号空缺与既有向量

- 决定：会话资源固定落在单桶 `res_<session_id>`（`raw/`、`documents.zip`、`index/`、`manifest.json`）；增量上传和纯删除通过 `manifest.document_roots` 映射文件与一级目录，仅处理新增/替换批次或裁剪目标文档，连续删除保留编号空缺，未变文档的路径、`chunk_id` 与向量行保持不变，并沿用旧清单模型与分块配置。
- 原因：保证历史对话中的数字引用在补传或删文件后仍能准确定位，同时避免整会话重解析与重算 embedding。
- 排除：每次增删文件后全量重新编号，或全量重跑解析与向量构建。

## 2. 产物损坏直接拒绝，不在资源层静默重建或加分布式锁

- 决定：所有校验在本地临时目录完成，校验通过才发布并更新 `raw/`；已有归档、映射或索引损坏时直接抛错拒绝增量/删除，不静默回退全量重建；同桶并发调用依赖 `backend` 串行化。
- 原因：静默重建会悄无声息破坏历史引用编号；单桶写串行化已由会话协调层保证。
- 排除：损坏时静默回退全量重算，或在资源发布层额外引入分布式锁。

## 3. 生产 CLI 预热默认模型，嵌入式测试入口默认不预热

- 决定：`main.run` 在后台线程加载默认 embedding 模型并跑通短文本编码后才监听 SERVING（预热失败阻止就绪）；`create_server` 嵌入式测试入口默认不预热。
- 原因：消除生产首个上传请求的冷启动延迟，同时避免本地测试被大模型加载拖慢。
- 排除：生产首次请求再懒加载，或测试入口强制加载真实大模型。

## 4. HTML 按 `h1`-`h6` 线性标题栈建树，块级节点统一数字前缀单 `.md` 落盘

- 决定：HTML 转 Markdown 文档树时线性扫描 `h1`-`h6` 与块级标签（`p`/`ul`/`ol`/`table`），通过维护 `section_stack` 重建嵌套目录，不依赖输入 HTML 的 `<section>` DOM 嵌套；不跳过正文 `h1`（文档内多个 `h1` 各自生成一级章节目录，首个 `h1`/`title` 仍用作文档顶层目录名后缀）；`p`、`ul`/`ol`、`table` 各自收敛为单个 `.md` 文件，段落与列表文件名截取前 24 个可见字符（`DEFAULT_SNIPPET_CHARS = 24`），同级统一使用三位数字前缀（`001-`）保证原文顺序并消除重名。
- 原因：PDF/OCR 产出的 HTML 常因分页打断 `<section>` 标签，线性标题栈更稳定；保留多 `h1` 建目录可防止多章节文档丢失一级结构；块级单 `.md` 落盘避免列表与表格节点爆炸。
- 排除：要求上游重写跨页 `<section>` 标签或建树时依赖 `<section>` 嵌套；跳过正文 `h1`；将列表或表格拆为多层子目录/逐项文件；省略数字前缀或使用 `...` / `--summary` 工程后缀。
