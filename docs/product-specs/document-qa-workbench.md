# TraceAgent 文档 QA 工作台产品规格

归属 [产品规格总目](index.md)。本页定义浏览器工作台（界面品牌名 `TraceAgent`）面向用户的核心行为与验收边界，不约束内部代码实现方式。

## 0. 产品定位与非目标

- 产品定位：面向敏感场景、单会话少量长文档（PDF/DOCX，单会话上限 20 文件、32 MiB）的可信可追溯文档 QA 工作台。核心价值是结合只读文档目录浏览与语义检索，展示可核查的查阅过程与原文段落证据链。
- 明确非目标：不保留早期结构化字段抽取、`route_policy` 自动判信及字段级人工审核/审批工作流；不定位为海量文档库全库黑箱 RAG 召回系统；产品界面与服务路由不内置实验数据集或实验展示页；暂不支持回答生成中途插话修改模型轨迹（仅支持随时取消当前轮后再追问）。

## 1. 文档上传与来源管理

- 首页采用单聚焦居中舞台（无左侧空栏与快捷提示卡），仅保留 `TraceAgent` 标题与一体化输入框（含回形针附件入口）；支持上传 PDF 与 DOCX 文档，选文件后在输入框内行内逐文件展示处理队列状态（排队中、处理中、就绪、错误红字与重试入口），单文件失败不阻塞其余文件；多次选择文件按文件名去重并追加合并到现有队列，不覆盖前序已选文件；队列全部就绪后自动进入会话详情页，未发草稿保留到详情页输入框且不写入 URL。
- 详情页默认以约对半宽度的左右分栏展开并允许自由拖拽（点击引用或切换回文件列表绝不重置用户拖拽后的宽度）；左侧 Sources 面板图标化呈现原始文件列表，支持搜索、点击文件名直接阅读、下载原文件、删除文件或点击 `+` 补传；聊天输入区不重复放置附件按钮。
- 补传或删除文件后，既有未删除文档的历史数字引用仍可正常打开并高亮对应原文；文件处理中、删除中或恢复连接期间，提问提交与文件变更互斥。

## 2. 多轮文档问答与过程可见

- 用户可围绕当前会话的文档连续发起多轮提问，也可直接询问非文档问题；允许连续发送与历史内容完全相同的重复追问，发送后立即乐观显示用户消息。
- 首页与详情页输入框统一使用 Enter 发送、Shift+Enter 换行（忽略输入法组合态与修饰键组合）；生成期间允许编辑下一轮草稿，但当前轮结束前不并发提交新轮。
- 边查边叙述与时间线呈现：涉及查文档时先简短说明查阅方向，每轮探索后用 1 至 3 句合并叙述查了什么、发现什么（附可读行内证据链接）及后续安排，不对零碎失败搜索逐条叙述；对话区采用左右气泡布局、不展示 You/AI 标签；过程叙述、连续工具折叠组与最终回答按原始时间线交错展示；失败工具沿用中性配色不标红干扰正文；运行等待态展示带三个跳动点的 `Thinking` 提示。
- 流式输出期间仅在用户停留在对话底部附近时自动跟随滚底，用户向上翻看历史时不强制拉回底部。

## 3. 主动取消、断连与页面恢复

- 回答生成期间，用户可随时点击取消立即停止当前轮；已取消轮次保留此前已完成的稳定历史，未完成的回答或工具过程标记为中断状态，不破坏后续继续追问。
- 刷新页面、关闭浏览器标签页或短暂网络断开只释放当前浏览连接，不等于主动取消后台正在生成的回答；重新打开同一会话链接后自动恢复完整历史、当前来源列表与正在进行的回答流，且网络重连不会自动重复提交上一条提问。

## 4. 数字引用与原文高亮阅读

- 仅最终回答启用紧贴句末的纯数字圆标引用（如 `[1]`，激活态呈沉静钢蓝），不在段落下方或文末单列 `Sources` 汇总列表；中间调查叙述保持可读文字形式的行内证据链接。
- 点击任意数字引用后，左栏由 Sources 列表切换为整篇文档阅读视图，以钢蓝柔光块（左侧贴边直竖条、右侧圆角无弯钩）高亮对应段落并仅滚动左侧文档容器（目标段已在可视范围内时不重复拉扯，且不重置用户拖拽后的左右分栏宽度），同时保留前后章节上下文；同文档内切换引用不重载全文，跨文档才加载新全文；顶部支持切换文档与关闭阅读器返回 Sources。
- 当引用的目标段落不存在或路径无效时，给出明确缺失提示，不错误高亮其他段落。

## 5. 跨标签页共享会话目录与可读标题

- 首轮提问后在后台异步由模型总结生成可读会话标题并持久化，同时推送到当前页面顶栏与最近会话抽屉；模型异常或超时时静默降级为首条提问或首个文件名摘要，无标题旧会话按同口径兜底派生（空会话回退 `Untitled workspace`），绝不展示 UUID。
- 打开最近会话抽屉可查看同一后端保存的最近会话列表（最多 100 条），不同标签页或不同浏览器访问同一后端时共享同一目录；接口失败时明确报错，不静默回退过期本地缓存。
- 空闲详情页在重获焦点或定时同步时自动拉取最新服务端状态，其他标签页新增或删除文件、发起问答后可保持一致；打开系统文件选择器或本页正执行操作时暂停自动刷新，避免打断当前操作。

## 6. 界面语言与双主题

- 工作台运行时全部可见文案、可访问性标签与错误提示统一使用英文。
- 顶栏收敛为 44px 极简图标栏并提供单按钮 Light/Dark 主题切换，刷新页面及跨标签页保持一致；Dark 模式下外层界面与右侧对话区切换为中性炭黑，左侧打开的原始文档纸面恒定保持白纸黑字。
