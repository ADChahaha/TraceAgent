# TraceAgent 文档 QA 工作台产品规格

归属 [产品规格总目](index.md)。本页定义浏览器工作台（界面品牌名 `Agent Gate`）面向用户的核心行为与验收边界，不约束内部代码实现方式。

## 1. 文档上传与来源管理

- 支持上传 PDF 与 DOCX 文档（单会话上限 20 个文件、单文件/批次受后端容量限制）；选文件后即逐文件进入处理队列并实时反馈状态（排队中、处理中、就绪、失败原因与重试入口），单文件失败不阻塞其余文件。
- 首页队列全部处理就绪后自动进入会话详情页；用户在上传期间输入的未发草稿保留到详情页输入框，不丢失也不写入 URL。
- 详情页可在左侧 Sources 面板查看原始文件列表、按文件名搜索、下载原文件、删除文件或点击 `Add files` 补传；聊天输入区不重复放置附件按钮。
- 补传或删除文件后，既有未删除文档的历史数字引用仍可正常打开并高亮对应原文；文件处理中、删除中或恢复连接期间，提问提交与文件变更互斥。

## 2. 多轮文档问答与过程可见

- 用户可围绕当前会话的文档连续发起多轮提问，也可直接询问非文档问题。
- 回答生成期间实时流式展示模型正文以及模型查阅文档的工具过程（浏览目录、关键词搜索、读取正文、语义检索）；连续工具调用折叠为过程组，允许查看查阅轨迹。
- 生成期间允许编辑下一轮提问草稿，但当前轮结束前不并发提交新轮。

## 3. 主动取消、断连与页面恢复

- 回答生成期间，用户可随时点击取消立即停止当前轮；已取消轮次保留此前已完成的稳定历史，未完成的回答或工具过程标记为中断状态，不破坏后续继续追问。
- 刷新页面、关闭浏览器标签页或短暂网络断开只释放当前浏览连接，不等于主动取消后台正在生成的回答；重新打开同一会话链接后自动恢复完整历史、当前来源列表与正在进行的回答流，且网络重连不会自动重复提交上一条提问。

## 4. 数字引用与原文高亮阅读

- 回答引用文档事实时，在句尾展示可点击的数字圆标引用（如 `[1]`）。
- 点击任意数字引用后，左栏由 Sources 列表切换为整篇文档阅读视图，自动滚动定位并淡黄色高亮对应段落，同时保留前后章节上下文；同文档内切换引用不重载全文，跨文档才加载新全文；顶部支持切换文档与关闭阅读器返回 Sources。
- 当引用的目标段落不存在或路径无效时，给出明确缺失提示，不错误高亮其他段落。

## 5. 跨标签页共享会话目录

- 打开最近会话抽屉可查看同一后端保存的最近会话列表（最多 100 条），不同标签页或不同浏览器访问同一后端时共享同一目录；接口失败时明确报错，不静默回退过期本地缓存。
- 空闲详情页在重获焦点或定时同步时自动拉取最新服务端状态，其他标签页新增或删除文件、发起问答后可保持一致；打开系统文件选择器或本页正执行操作时暂停自动刷新，避免打断当前操作。
