# 工作区与协作规范偏好

本页属 [偏好索引](INDEX.md)，记录本仓库跨会话的语言习惯、记忆分层预算与 Dreaming 提交规范。

## 沟通与文档习惯

- **默认中文沟通与说明**：回复、新增说明、注释和 docstring 默认使用中文，保留标准英文术语。
- **格式约束**：遵循 [AGENTS.md](../../AGENTS.md)，不使用 em dash、智能引号或装饰性 Unicode，统一使用普通连字符、直引号和可复制代码。
- **长文档按主题分层拆分**：不仅限 `memory/`，各包 `docs/` 的设计/接口文档与调研、实验分析文档偏长或含多子主题时，均拆分为轻量总览索引页 + 同级相对路径子文件，索引页与子文件分别对齐 L1/L2 体量习惯（已写入 [AGENTS.md](../../AGENTS.md)）。
- **规则表述克制**：启动与协作规则直写简洁原则（如按需读取），不堆死板条件清单。

## 多层按需记忆与体量预算

- **分层按需查找（L0 -> L1 -> L2 -> L3）**：禁止在 L0 顶层平铺细节或把长文压成单行；新会话先读 L0 [memory.md](../../memory.md) 与 `memory/notes/`，其余沿 L1 路由按需打开。
- **单文件硬预算（由 `dream_scan.py --audit` 守门）**：
  - L0 `memory.md`：`<= 1500` 字符、`<= 35` 行、单行 `<= 200` 字符，且只连 L1 索引。
  - L1 领域索引：`<= 2200` 字符、`<= 45` 行、单行 `<= 220` 字符。
  - L2 专题与偏好页：`<= 2600` 字符、`<= 65` 行、单行 `<= 260` 字符。
  - L3 实证与明细页：`<= 2400` 字符、`<= 55` 行、单行 `<= 260` 字符。
- **单源去重与反互链墙**：每条事实只落一个权威页，不复抄源码或各包 `docs/DESIGN.md` 全文；L2/L3 单行内部 `.md` 链接不超过 5 个。

## Dreaming 与提交习惯

- **先剪枝后归并、门禁全绿再提交**：手动运行 `dreaming` 并经 `python3 memory/dream_scan.py --audit` 确认 6 项门禁清零且受保护规则文件哈希未变后，创建原子 `git commit`；仅暂存 `memory/`、`memory.md` 及相关技能改动，不混入未完成业务代码。
