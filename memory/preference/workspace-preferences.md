# 工作区与协作偏好

归属 [偏好索引](INDEX.md)，记录本仓库跨会话的写作风格、文档组织、记忆架构与提交习惯。

## 沟通与文档写法

- 默认中文沟通，新增文档、注释和 docstring 使用中文（标准英文术语除外）。
- 表达直接平实，按事实与实现写，不用破折号、弯引号和装饰性符号，不堆砌粗体标签，不写规则腔套话，也不在多个文件里反复复述同一套规矩。
- 各包偏长的设计与接口文档按"轻量总览索引页 + 同级主题子文件"维护，修改前顺索引按需阅读对应子文件；`README` 与 `tests/docs/` 保持单文件。

## 验收驱动与决策记录

- 开发以用户确认的外部验收标准为锚点，代码实现面向增加、谨慎修改既有稳定逻辑；优先用外部行为测试与实测证据验收，跨服务、并发或高风险改动在自验后增加一次独立视角的只读核查。
- 对话中用户拍板的决策当轮即时落盘，固定写明三要素：做了什么决定、为什么这么选、排除了哪些备选方案。
- 决策按"包 -> 具体模块"就近写入对应 `DECISIONS.md`（独立子模块自带 `docs/` 时放 `<module>/docs/DECISIONS.md`，其余放 `<pkg>/<module>/DECISIONS.md`，并在对应包 `docs/DESIGN.md` 挂链接）；跨包架构决策入 `memory/wiki/`，协作习惯入本目录，不另建全仓单一 `DECISIONS.md` 或 `docs/adr/`。
- 复杂或跨会话任务复用 `memory/tasks/<topic>.md` 作施工暂存（目标与范围、验收标准、决策记录）；归档进 `memory/archive/` 前必须逐条迁出长期决策并标注去向（或确认仅本次临时有效），未迁完不归档。

## 记忆架构与防膨胀

- 坚持四层按需记忆结构（L0 -> L1 -> L2 -> L3）与 `dream_scan.py --audit` 六项门禁，精简文风时不拍平分层或削弱门禁；具体层级预算见 [memory/docs/DESIGN.md](../docs/DESIGN.md) 与 [dreaming/SKILL.md](../../.agents/skills/dreaming/SKILL.md)。
- 单源去重：每条事实只落一个权威页，其他页留简短指针，不复抄源码、设计文档全文或已有规则清单。
- 不靠压成长单行躲行数检查；逼近预算时先删过期与重复内容，再下沉细节到 L3 或拆分子页。

## Dreaming 与提交习惯

- 手动执行 `dreaming` 并通过 `python3 memory/dream_scan.py --audit`（六项门禁清零且 `AGENTS.md` 哈希未变）后，做一次原子 commit，仅暂存 `memory/`、`memory.md` 及相关技能变更，保留无关工作区目录（如 `storage/data/`）。
