# 工作区与协作偏好

本页属 [偏好索引](INDEX.md)，记录本仓库跨会话的沟通写法、四层记忆预算与 Dreaming 提交习惯。

## 沟通与文档写法

- 默认中文沟通，新增文档、注释和 docstring 用中文（标准英文术语除外）。
- 表达直接平实，避免模板腔、堆砌粗体标签、破折号、弯引号、装饰性符号，以及把同一套话在多个文件里反复复述。
- 文档和记忆以事实和实现为主；内容偏长或含多子主题时，拆成轻量总览索引页 + 同级相对链接子文件，`README` 与 `tests/docs/` 保持单文件。

## 四层按需记忆与体量预算

- 按 `L0 -> L1 -> L2 -> L3` 分层按需查找，不在顶层平铺细节，不靠压成长单行躲行数限制。
- 单文件硬预算由 `python3 memory/dream_scan.py --audit` 守门：
  - L0 `memory.md`：`<= 1500` 字符、`<= 35` 行、单行 `<= 200` 字符，且只连 L1 索引。
  - L1 领域索引：`<= 2200` 字符、`<= 45` 行、单行 `<= 220` 字符。
  - L2 专题与偏好页：`<= 2600` 字符、`<= 65` 行、单行 `<= 260` 字符。
  - L3 实证与明细页：`<= 2400` 字符、`<= 55` 行、单行 `<= 260` 字符。
- 单源去重与反互链墙：每条事实只落一个权威页，不复抄源码或各包 `docs/DESIGN.md` 全文；L2/L3 单行内部 `.md` 链接不超过 5 个。

## Dreaming 与提交习惯

- 手动运行 `dreaming` 并经 `python3 memory/dream_scan.py --audit` 确认 6 项门禁清零且 `AGENTS.md` 哈希未变后，做一次原子 commit，仅暂存 `memory/`、`memory.md` 及相关技能变更，不混入无关业务文件。
